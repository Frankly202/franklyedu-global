# FranklyEdu Vision

Build a responsive working prototype for FranklyEdu Global based closely on the existing Framer site:

https://franklyedu.framer.website/

Use the attached screenshots as the visual reference. Preserve the overall visual language: deep navy/blue palette, cream/white sections, rounded cards, bold modern typography, compact navigation, and the current clean education-platform feel.

Create a functional frontend prototype with connected routes for:

Home, Universities, Courses, Countries, Scholarships, Services, Marketplace, About, Contact, Login, Sign Up, Application, Student, Accommodation and Real Estate.

The homepage should closely follow the Framer structure: navbar, hero with study-search UI and CTA buttons, destination cards, university/course cards, student-support services, and final WhatsApp CTA.

Make navigation and buttons actually work using mock/static data. No real backend, authentication, payments or database yet.

Make everything fully responsive across desktop, tablet and mobile.

Keep all editable content/data centralized and easy to replace later, especially:

- FranklyEdu logo/favicon

- Hero/background image

- Navigation labels

- Colours/typography

- Universities/courses/destinations

- Contact/WhatsApp details

Use placeholder/mock data where necessary. Prioritize a clean, production-quality UI and accurate visual direction over backend functionality.

Do not add features outside this scope.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
